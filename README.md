# Dyna-Q-Maze-Navigation-RL

CAVR-Dyna: Context-Aware Variational Reinforcement Learning with Dyna-Q planning for dynamic maze navigation.

## Structure

- `cavr-dyna/` — RL research implementation (src, scripts, notebooks, tests, configs, artifacts)
- `webapp/` — Next.js frontend + server
- `presentation-slides/` — slide decks
- `CAVR-Dyna-Presentation.pptx` — presentation
- `CAVR-Dyna-Project-Report.docx / .pdf` — project report
- `INTEGRATION-README.md` — integration notes
