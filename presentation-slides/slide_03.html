PROBLEM STATEMENT

Navigation that changes while you are learning it

The agent acts in a 9×9 grid maze formalized as an MDP M = ⟨S, A, P, R, γ⟩. Actions slip: with probability 1−ρ the intended move executes, otherwise a uniformly random passable move — so even the transition table is stochastic before the world starts changing.

Topology then changes mid-run: edges get blocked or hidden shortcuts open at evaluator-chosen times, invisible to the agent (leak guard: only (s, a, r, s′) tuples are exposed). A Dyna agent that trusts its learned model keeps re-using stale experience precisely where the world moved — adaptation delay explodes.

ρ ∈ {0, 0.1, 0.3}
action slip levels evaluated
{blocking, shortcut, static}
change scenarios
640
pilot runs · 8 map/seed pairs
Success measured post-change; adaptation delay = steps until rolling success recovers, censoring-aware.
